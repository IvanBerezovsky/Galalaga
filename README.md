Игра Cosmo's Quest.

В игре есть несколько (3-5) уровней.

Игрок управляет космическим кораблем, можно двигаться вправо и влево. Игрок может стрелять вверх.
Сверху на игрока летят препятствия, в них нужно стрелять.

Препятствия (возможны дополнения):
  1. Маленький метеорит (летит вниз, умирает за 1 выстрел)
  2. Большой метеорит (летит вниз, умирает за 3 выстрела)
  3. НЛО (Летит по горизонтали, каждый раз спускаясь все ниже, умирает за 3 выстрета)

Игрок начинает игру с 10 очками. При пропуске препятствий у игрока отнимаются очки, при достижении 0 очков игрок проигрывает.
За каждое разрушение препятствия игроку дается некоторое количество очков.
Для прохождения уровня нужно набрать некоторое количество очков.
